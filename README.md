# Study-Kasus-3-Muh.Agustyon
untuk study kasus kali ini, saya membuat sistem sederhana untuk meminjam buku, saya membuat logic sederhana yaitu jika input buku yang tersedia di tuble daftar_buku, maka buku tersebut akan masuk ke dalam list pinjaman, lalu jika buka tersebut ada di list pinjaman, maka akan ngeprint "buku sudah di pinjam", terakhir jika buku yang di input sama sekali tidak ada di tuble daftar_buku, maka akan ngeprint "buku tidak tersedia"

lalu saya juga buat fitur hapus sederhana, dengan menginput "hapus" di dalam input "buku", maka akan masuk ke input "hapus", disini akan langsung print list pinjaman, lalu untuk menghapus buku yang ada di list pinjaman, tinggal memasukkan nama buku yang ada di list pinjaman, jika sudah menginput bukunya, maka akan menghapus buku yang ada di list pinjaman, lalu jika menginput buku yang tidak ada di list pinjaman maka akan ngeprint "buku tidak ada dalam daftar pinjaman", lalu untuk kembali untuk meminjam buku, tinggal memasukkan "selesai" di dalam input "hapus" dan akan kembali ke input "buku"

dan untu mengakhiri peminjaman, tinggal memasukkan "selesai" juga di input "buku" maka akan muncul daftar buku yang di pinjam
